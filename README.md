# misc_dsp

Репозиторий с различными dsp модулями. 

<p>

> *Основное:*
> - *Использовать на свой страх и риск.*
> - *В первую очередь предназначены для использования с ПЛИС Xilinx.*
> - *В разработке используется TerosHDL (поэтому такие странные комментарии).*
> - *Один модуль - одна пакпка. В папке - небольшая документация на модуль.*

<p>

<details>

**<summary> Краткое описание модулей в папке </summary>**

>### AGC_matlab
>Модуль АРУ по мотивам схемы из matlab.

>### exponenta_tabular
>ПЗУ экспоненты c автоматическим вычислением значений.

>### log_nat_tabular
>ПЗУ натурального логарифма c автоматическим вычислением значений.

>### level_estimator
>Модуль вычиисления уровня комплексного сигнала на основе алгоритма альфа макс бета мин

>### NCO
>Mодуль генератора, управляемого кодом.

</details>
